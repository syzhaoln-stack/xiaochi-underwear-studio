# Blender 教学资产

这些资产由本机 **Blender 4.5.13 LTS** 真实生成，源脚本为 `build_assets.py`。

- `../assets/mannequin.glb`：只有灰白下身人台，适合网页叠加参数化服装。
- `../assets/briefs-demo.blend`：高腰、中腰两款穿着示意；前片、后片、裆外片、棉质裆里片均为独立对象，另有四片平铺示意。
- `../assets/blender-preview.png`：Blender Cycles 渲染，1600 × 1100。
- `../assets/mannequin-profile.json`：人台坐标和轮廓参数。

## 坐标

GLB 使用米、Y 向上、+Z 朝前；Blender 源场景使用 Z 向上、-Y 朝前，导出自动转换。

| 标记 | GLB Y 高度 | 横向半宽 | 前后半深 |
|---|---:|---:|---:|
| 腰线上方截口 | 0.450 | 0.156 | 0.105 |
| 高腰腰线 | 0.350 | 0.158 | 0.106 |
| 中腰腰线示意 | 0.270 | 0.169 | 0.115 |
| 臀围线 | 0.120 | 0.190 | 0.140 |
| 裆部附近 | 0.000 | 0.110 | 0.084 |
| 大腿截口 | -0.350 | — | — |

人台约对应自然腰围 84 cm、臀围 104 cm。网格经过平滑和减面，轮廓并非量体扫描；大腿融合处与椭圆辅助轮廓略有差别。

## 用途边界

该场景用于说明款式、缝合位置和四块布的组成，**没有进行布料物理仿真**。Blender 中的平铺样例是构造示意，不是可以直接打印裁剪的最终纸样；尺寸计算与 SVG 纸样以网页中的参数为准，并需要用同批面料试样确认。

## 重建

从应用根目录运行，需要 Blender 和可在命令行访问的 Node.js 22 或更新版本。脚本读取 `pattern.js` 的真实净样轮廓生成四片平铺，默认左右 C 拼缝各前移 3 cm；该值仅为场景演示。

```powershell
blender --background --python '.\blender\build_assets.py'
```

重建会更新上述四个资产文件。场景物体名称可用于分别选择前片、后片、外裆片、棉质里裆片和松紧包边。
